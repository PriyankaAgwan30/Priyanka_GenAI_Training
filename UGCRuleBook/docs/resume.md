## UGCRuleBook – AI-Powered Student Rights Assistant

- Developed UGCRuleBook, a Retrieval-Augmented Generation (RAG) application that answers student-rights queries using UGC regulations and source citations.
- Implemented semantic document retrieval using Sentence Transformers and ChromaDB, integrated with Google Gemini through FastAPI and Streamlit.
- Added response caching, input validation, latency and token logging, and automated API testing using Pytest to improve reliability and performance monitoring.
